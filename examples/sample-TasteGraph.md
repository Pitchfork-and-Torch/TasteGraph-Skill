## Core identity
- **Sovereign builder**: Prefers owned stacks and local-first tools over platform rent as default.
- **Dual register maker**: Switches between intimate atmospheric work and precise systems surfaces without blending them.
- **Portfolio solar system**: Many distinct planets under one craft gravity; resists homogenized landings.

## Hard loves
- [visual] **Object as hero**: One crafted physical metaphor owns the viewport; chrome nearly invisible.

## Hard antis
- [visual] **Effect soup**: Glass + beam + aurora + 3D + confetti stacked without hierarchy.
- [visual] **Purple glass 2021**: Dated maximal frosted purple glassmorphism as default system look.
- [color] **Neon vomit on product UI**: Toxic multi-neon overload on dashboards and product chrome. Loud collage may be OK on pure art/fashion planets only.
- [process] **Fake social proof**: Fake testimonials, spam scarcity timers, conversion theater.
- [visual] **AI trend mash**: Every internet trend in one frame (chrome skull + vaporwave + matrix + lens flares).
- [motion] **Scroll-jack mobile**: Multi-pin chaos and stolen scroll on mobile.

## Motion stack
1. **CSS micro** - Default. High-frequency chrome may be 0ms.
2. **Lightweight JS timelines** - Mid complexity: stagger, SVG, object tweens (e.g. Anime.js class tools).
3. **Scroll cinema** - Pinned chapters, scrubbed storytelling (GSAP-class).
4. **3D last** - Three.js product 3D. Never always-on game loops on marketing chrome.

## Process values
- **First-pass ship**: Complete gate once; avoid multi-deploy fix storms.
- **Polish threshold**: High on public flagships and object-hero stills; concept without museum finish is a miss.
- **Register before style**: Classify planet/mode before inventing visual direction.
- **Evidence over vibes**: Update graph from scored outcomes and explicit feedback.

## Collaboration protocol
1. **Classify**: Pick emotional register / surface class before inventing style.
2. **Load nodes**: Apply matching density, color, motion, and non-negotiable antis.
3. **Distance check**: New work must not clone the nearest sibling planet. Prefer distinct worlds.
4. **Prove once**: If multi-modal, show variants. Ship with complete gate. Log outcome to evidence_log.
