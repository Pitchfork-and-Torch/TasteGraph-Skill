# TasteGraph brand assets

## Mark

A gold constellation graph on charcoal: **one hero node** at the center, satellite nodes and edges as a living preference graph. Intentional empty space. No glass, neon, or effect soup.

## GitHub social preview

In the repo: **Settings -> General -> Social preview -> Edit** and upload `social-preview.png` (or `social-preview.jpg`).

README already embeds the icon and banner so the page features the mark without that setting.
